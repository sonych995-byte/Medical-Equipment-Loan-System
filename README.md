# ระบบยืมครุภัณฑ์ทางการแพทย์ (Medical Equipment Loan System)

ระบบสำหรับจัดการการยืมและคืนครุภัณฑ์ทางการแพทย์ ของโรงพยาบาลบ่อพลอย จังหวัดกาญจนบุรี เพื่อลดขั้นตอนการทำงานด้วยเอกสารกระดาษ และเพิ่มความสะดวกในการบันทึกและค้นหาข้อมูล

## วัตถุประสงค์

ระบบนี้ถูกพัฒนาขึ้นเพื่อ:
- บันทึกข้อมูลการยืมครุภัณฑ์ทางการแพทย์ เช่น เตียงผู้ป่วย, ที่นอนลม, เครื่องผลิตออกซิเจน
- จัดเก็บข้อมูลผู้ป่วยและผู้ยืม พร้อมรูปถ่ายบัตรประชาชน
- คำนวณค่ามัดจำครุภัณฑ์แต่ละรายการ
- พิมพ์เอกสารใบยืมและแบบส่งคืนครุภัณฑ์
- ติดตามสถานะการยืมและคืนครุภัณฑ์

## เทคโนโลยีที่ใช้

- **Backend:** Google Apps Script (Code.gs)
- **Frontend:** HTML, Vue.js 3, Bootstrap 5, Font Awesome, SweetAlert2
- **ฐานข้อมูล:** Google Sheets
- **พื้นที่จัดเก็บรูปภาพ:** Google Drive

## ฟีเจอร์หลัก

- ฟอร์มบันทึกการยืมครุภัณฑ์
- การเลือกครุภัณฑ์และระบุเลขครุภัณฑ์
- การอัปโหลดรูปบัตรประชาชนผู้ป่วยและผู้ยืม
- ระบบเข้ารหัสข้อมูลส่วนบุคคลก่อนบันทึกลงฐานข้อมูล
- หน้าจอรายงานการยืมและสถานะการคืน
- หน้าจอสำหรับบันทึกการส่งคืนครุภัณฑ์
- ระบบพิมพ์เอกสารใบยืมและแบบส่งคืน

## สิ่งที่ต้องเตรียมก่อนติดตั้ง

- บัญชี Google (สำหรับใช้งาน Google Apps Script, Google Sheets และ Google Drive)
- สิทธิ์ในการสร้างและ Deploy Web App ผ่าน Google Apps Script

## วิธีการติดตั้ง

1. **สร้าง Google Apps Script Project**
   - ไปที่ [Google Apps Script](https://script.google.com/)
   - สร้างโปรเจกต์ใหม่

2. **สร้างไฟล์ในโปรเจกต์**
   - สร้างไฟล์ `Code.gs` และวางโค้ด Backend
   - สร้างไฟล์ `Index.html` และวางโค้ด Frontend

3. **สร้างฐานข้อมูล Google Sheets**
   - สร้าง Google Sheet ใหม่
   - ตั้งชื่อ Sheet ว่า `ใบยืมครุภัณฑ์ทางการแพทย์`
   - คัดลอก URL ของ Sheet เพื่อเชื่อมต่อ (หากจำเป็น)

4. **Deploy Web App**
   - คลิกที่ `Deploy` > `New deployment`
   - เลือกประเภท `Web app`
   - ตั้งค่า `Execute as` เป็น `Me`
   - ตั้งค่า `Who has access` เป็น `Anyone` หรือ `Anyone with Google account`
   - คลิก `Deploy` และคัดลอก URL ของ Web App

## วิธีการใช้งาน

1. เปิด URL ของ Web App ที่ได้จากการ Deploy
2. ในแท็บ `ฟอร์มยืมครุภัณฑ์` กรอกข้อมูลผู้ป่วยและผู้ยืมให้ครบถ้วน
3. อัปโหลดรูปบัตรประชาชน (ถ้ามี)
4. คลิก `เพิ่มรายการครุภัณฑ์ที่ต้องการยืม` เพื่อเลือกครุภัณฑ์และระบุเลขครุภัณฑ์
5. ตรวจสอบยอดรวมค่ามัดจำ
6. คลิก `บันทึกข้อมูล` เพื่อบันทึกข้อมูลลง Google Sheets
7. คลิก `พิมพ์เอกสาร` เพื่อพิมพ์ใบยืม

### การส่งคืนครุภัณฑ์

1. ไปที่แท็บ `ส่งคืนครุภัณฑ์`
2. ค้นหารายการที่ต้องการส่งคืน
3. คลิก `ส่งคืน` และกรอกวันที่คืนและชื่อผู้รับ
4. คลิก `บันทึกการคืน` และพิมพ์แบบส่งคืน (ถ้าต้องการ)
